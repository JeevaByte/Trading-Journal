# Trading Journal

A comprehensive trading journal application built with Next.js, designed to help traders track, analyze, and improve their trading performance.

## ✨ Features

- 📊 **Trade Management** - Log and manage all your trades
- 📈 **Analytics Dashboard** - Visualize your trading performance with charts and statistics
- 📝 **Journal Entries** - Document your trading thoughts and strategies
- 📚 **Playbooks** - Create and follow your trading playbooks
- 💬 **Community** - Connect with other traders
- 💳 **Subscription Management** - Manage your premium features
- 📥 **CSV Import** - Import trades from your broker

## 🚀 Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the application.

## 🛠️ Tech Stack

- **Framework:** Next.js 15
- **Styling:** Tailwind CSS
- **UI Components:** shadcn/ui
- **Database:** Prisma ORM
- **Authentication:** NextAuth.js

## 📦 Project Structure

```
src/
├── app/              # Next.js app directory
├── components/       # React components
├── lib/             # Utility functions and actions
└── middleware.ts    # Authentication middleware
```

## 🔧 Configuration

1. Set up your environment variables
2. Configure your database with Prisma
3. Set up authentication providers
